# Unattached Codex native proxy

This package is a source-only prototype on Deck `753328a9db95f78b9d98766d26968bce717ba98c`. No existing command, daemon, MCP entry, configuration loader or session lifecycle imports it. It cannot discover a socket, execute a CLI, send terminal keys, kill a process, launch queued work or accept a trust prompt.

A future reviewed constructor must provide the exact owner/machine/Deck-session binding, native incarnation, permanent authority epoch, upstream revision plus verified native patch SHA, private socket and directory inode identities, and peer UID/PID. The Linux proxy checks canonical paths, private owner modes, non-symlink protected ancestors, one-link socket identity and `SO_PEERCRED`, then rechecks filesystem identities before sending and after receiving. A root-owned sticky ancestor such as the temporary directory is allowed; the direct capability directory remains exactly `0700`. Other platforms refuse. No native or installed-platform qualification is claimed by these checks.

A successful exact pinned observation on that same capability is required before any Answer/Stop bytes. Source pins are not inferred from construction alone. Each exchange is a single-flight operation with a total constructor-selected deadline of at most five seconds. Mutations also respect the original approval and command deadlines. Frames contain a four-byte big-endian length and at most 65,536 strict UTF-8 JSON bytes. The caller half-closes after one request; the provider closes after one response. Missing EOF, extra bytes, invalid UTF-8, duplicate decoded keys, unknown fields, nulls in required typed fields or mismatched correlations refuse. Raw errors and provider messages never escape. The proxy never retries.

The original authority envelope is a lease from the trusted paired bridge, not a claim of instantaneous server-side revocation. The existing MCP executing journal must be fsync-durable before provider IPC. Native receipts are bounded memory-only metadata and a fresh incarnation is created on process/load restart. The native gate performs final owner/epoch/generation/deadline checks; no native fsync or persistent-receipt claim is made. A valid receipt is evidence only for its exact command, delivery, request hash, incarnation, native thread, generation and selected option. Missing/conflicting receipt lookup does not establish that the original action was unentered, and never authorizes a resubmit.

Before a valid revoke attempt waits or dials, the proxy holds further local mutations permanently. An exact `revoked` response proves the native gate acknowledged permanent disablement; a missing or malformed reply stays uncertain. A local hold alone cannot prove native revocation. The native provider's serialized gate must prove no effect after acknowledgment; this package's synthetic endpoint tests prove only forwarding and the additional local hold.

`proxy_linux_test.go` uses isolated temporary sockets, synthetic peer identity and source pins, and three shared vectors copied byte-for-byte from the MCP adapter. It exercises actual framing, both source pins, native prompt commitments, original receipt lookup, post-revoke refusal, changed owner/peer/inodes, private-path modes, malformed replies, bounded timeout and no resend. It does not prove native Codex prompt atomicity or journal durability. Go and gofmt were unavailable on the authoring PC, so Go compile/test/format verification must occur in the existing remote CI lane. No toolchain installation is part of this work.

The pending full-chain proof must use the real synthetic Rust provider, this actual Go proxy, and the MCP codec/adapter with isolated private IPC. It must retain native generation races, local-answer races, the existing MCP fsynced executing-record crash recovery, read-only receipt lookup, safe-idle graceful Stop, owner denial, source-pin mismatch and no terminal fallback. An installed provider, runtime qualification allowlist, host configuration, grants and any VM acceptance remain unattached and unexecuted.
